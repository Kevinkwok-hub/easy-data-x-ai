## 指标口径

- Hit@1 / Hit@3：前 1 / 3 条结果中是否出现标注证据。
- MRR：首条正确证据排名的倒数。
- 上下文精确率 / 召回率：检索结果中的相关证据比例与标注证据覆盖率。
- 可回答案例通过率：回答成功、引用校验通过，且检索结果与引用覆盖全部标注证据的比例。
- 拒答准确率：证据不足案例被安全拒答的比例。
- Token 为字符长度推算值，只用于本地方案对比，不等同于供应商账单。
